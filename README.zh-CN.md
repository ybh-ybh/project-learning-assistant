# Project Learning Assistant

[English](README.md) | [简体中文](README.zh-CN.md)

Project Learning Assistant 是一个 Codex Skill，用于将本地开源项目转换为循序渐进的 Markdown 课程，重点讲解项目架构、核心机制和源码阅读路径。

> [!CAUTION]
> **这个 Skill 会消耗非常多的 Token。**
>
> 它需要阅读项目文档和源码、制定针对当前项目的课程大纲，并生成多篇详细课程。仓库越大、学习范围越广、课程节数越接近 8–10 节，消耗的 Token 或使用额度通常越多。请在确认大纲前认真检查课程范围；必要时缩小学习范围或减少课程节数。

## 主要能力

- 根据本地项目中的真实文件进行分析，不依赖远程仓库简介生成课程。
- 澄清项目路径、课程语言、课程节数、学习目标和输出目录。
- 根据项目实际规模和复杂度，在 3–10 节范围内推荐课程数量。
- 用户主动指定的课程节数不受 3–10 节限制，该范围只用于默认推荐。
- 默认学习目标是理解技术架构和核心源码，不要求部署或运行项目。
- 先生成循序渐进的课程大纲；需要继续生成课程时，等待用户明确确认。
- 大纲确认后，根据请求生成全部课程、指定课程或定向更新某一节课程。
- 根据本地项目结构生成 Mermaid 整体架构图或组件关系图。
- 在讲解代表性核心源码流程的课程中生成 Mermaid 关键调用链路图。
- 根据本地源码核对引用路径、重要代码符号以及关键调用或数据流关系。
- 区分有源码依据的事实、分析推断和无法确认的信息。
- 不覆盖、删除或清空用户已有文件。
- 支持只生成大纲、只生成指定课程以及定向更新某一节已有课程。

## Token 消耗说明

这是一个有意设计为深度分析型、因而非常消耗 Token 的 Skill。Token 消耗主要受到以下因素影响：

- 仓库规模和模块数量；
- 学习目标的覆盖范围；
- 用户要求的课程节数；
- 需要解释的核心源码和跨模块流程数量；
- 需要生成和验证的 Mermaid 图表数量及复杂度；
- 修改大纲或课程后重新生成的内容量。

减少 Token 消耗的建议：

1. 尽量只选择真正需要学习的本地项目或子模块。
2. 第一次了解项目时，可以先生成 3–5 节课程。
3. 优先使用默认的“理解架构和核心源码”目标，不要求穷举所有实现细节。
4. 确认大纲前认真检查课程范围和节数。
5. 后续优先修改单节课程，不要重复生成整套课程。

大纲确认后，Skill 默认本地源码不会发生变化。它不会重新执行项目初步调查、全项目分析、版本检查或工作区检查，只会读取编写和验证每节课程所需的源码文件。

## 工作流程

### 1. 澄清需求并分析项目

Skill 会确定以下五项信息：

- 本地项目目录；
- 课程语言；
- 课程节数；
- 学习目标；
- 输出目录。

确认完成后，它会分析本地项目文档、模块结构、核心概念、源码入口和具有代表性的跨模块流程。

### 2. 生成课程大纲

Skill 首先只生成课程大纲，在其中记录本地项目版本和工作区状态，并加入 Mermaid 整体架构图或组件关系图。需要继续生成课程时会请求用户确认或修改；仅大纲模式到此结束。

用户确认前不会生成任何课程内容文件。

### 3. 生成完整课程

用户明确确认大纲后，Skill 会根据请求生成全部课程或指定课程，也可以只更新某一节已有课程而不重建整套课程。每节课以学习目标开篇，讲解相关概念和实现机制，提供经过核对的源码阅读路线，分析有依据的设计取舍，并以思考题收尾。讲解代表性核心源码流程的课程还会包含 Mermaid 调用链路图。

## 安装

将本仓库放入 Codex Skills 目录，并将目录名称保持为 `project-learning-assistant`。

常见位置：

```text
# Windows
C:\Users\<username>\.codex\skills\project-learning-assistant

# macOS 或 Linux
~/.codex/skills/project-learning-assistant
```

安装后的目录中必须包含 `SKILL.md`、`agents/` 和 `references/`。

## 使用方法

使用 `$project-learning-assistant` 调用 Skill，并提供本地项目路径。

```text
使用 $project-learning-assistant 为 D:\code\langchain4j 生成中文课程，
重点学习项目架构和核心源码。
```

也可以直接指定课程节数和输出目录：

```text
使用 $project-learning-assistant 为 D:\code\deepseek-harness 生成 8 节英文课程，
输出到 D:\notes\deepseek-harness-course。
```

如果缺少部分参数，Skill 会给出推荐值并请求用户确认。

也可以只生成或更新部分内容：

```text
使用 $project-learning-assistant 只为 D:\code\langchain4j 生成课程大纲。

使用 $project-learning-assistant 根据已确认的大纲生成第 03 和第 05 课。

使用 $project-learning-assistant 只更新第 04 课，让源码走读更加清晰。
```

## 输出文件

一套经过确认的 5 节中文课程可能包含：

```text
<项目名称>-course/
├── 00_课程大纲.md
├── 01_项目目标与整体认知.md
├── 02_系统架构与模块边界.md
├── 03_核心机制.md
├── 04_核心源码走读.md
└── 05_完整调用链路.md
```

课程文件名和正文使用需求澄清阶段确定的语言，代码标识和项目相对路径保持原样。

## 重要边界

- 目标项目必须已经下载到本地，只提供 GitHub 或其他远程仓库链接是不够的。
- Skill 不会用远程仓库分析或自动克隆代替本地文件。
- 默认不包含项目部署和运行。
- 大纲确认前不会创建课程占位文件。
- 输出目录非空时，Skill 会在写入前先询问用户；明确更新已有课程或在现有课程中生成指定课程时除外，但不会修改请求范围外的文件。
- 用户指定的输出目录不存在时，确认路径后会直接创建。
- 非 Git 项目无法识别版本时，只标记为版本未知，不生成额外快照标识。
- Skill 既支持系统自动发现，也支持使用 `$project-learning-assistant` 显式调用。
- Mermaid 图用于辅助正文讲解，不能替代源码走读路线。
- Mermaid 图中的项目模块、节点和调用关系必须能够从本地项目中验证。
